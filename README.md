# Training

Self-hosted дневник тренировок для телефона: подходы, авто-прогрессия весов, редактируемая программа, графики прогресса и «тренер», роль которого выполняет Claude Code. Несколько пользователей, каждый видит только своё.

## Быстрый старт (Docker)

```bash
curl -fsSL https://raw.githubusercontent.com/alexbelens/training/main/scripts/install.sh | bash
```

Скрипт создаст папку `training/` с `compose.yml`, `.env` и `data/`, скачает образ `ghcr.io/alexbelens/training` и запустит сервис на порту 8080. Открой `http://<ip>:8080`, зарегистрируйся — первый аккаунт становится администратором.

Вручную: скопируй `compose.yml` и `.env.example` → `.env`, заполни `COACH_TOKEN` и `PUBLIC_URL`, затем `docker compose up -d`.

### Обновление

В интерфейсе появится баннер, когда на GitHub выйдет новый релиз. На сервере:

```bash
./update.sh
```

Перед обновлением делается бэкап базы. Данные лежат в `./data` и не трогаются.

## Возможности

- **Тренировка** — выбираешь день A/B/C, для каждого упражнения готова рекомендация «вес × повторы × подходы», кнопка «применить», ввод подходов, боль в колене 0–10, заметка.
- **Программа** — техника, тренажёр, ссылка на фото; редактирование с историей версий и откатом; валидатор не пропустит запрещённые упражнения из профиля.
- **Прогресс** — вес тела с целевой линией, боль по тренировкам, рабочий вес по упражнению, тоннаж.
- **Тренер** — кнопки «Разбор» и «Пересобрать программу» создают запрос; Claude Code читает базу через coach-API, оставляет отчёт и план весов, при необходимости сохраняет новую версию программы.
- **Настройки** — профиль (травмы, ограничения, цели), смена пароля, экспорт/импорт JSON, администрирование пользователей, проверка версии.

## Правила авто-прогрессии

Рабочий вес — максимум в последней сессии. Все подходы с целевыми повторами → +шаг (2,5 кг по умолчанию, у упражнения можно задать свой). Недожал → тот же вес. Для упражнений с флагом «колено»: боль 4–5 → −15%, 6+ → −30%. «Без прогрессии» — вес не растёт. Адаптационный период — 2 рабочих подхода. Правила покрыты тестами: `npm test`.

## Тренер = Claude Code

В `.env` есть `COACH_TOKEN`. Claude Code (или любой скрипт) с этим токеном и заголовком `X-User-Id` получает экспорт пользователя, рекомендации и пишет отчёты:

```bash
COACH_SSH=myhost ./scripts/coach.sh users
COACH_SSH=myhost ./scripts/coach.sh export 1
COACH_SSH=myhost ./scripts/coach.sh report 1 report.json
```

Инструкция для Claude — в `.claude/skills/coach/SKILL.md`. Открой репозиторий в Claude Code и попроси: «тренер, разбери мои тренировки».

## Восстановление пароля

Если в `.env` задан `SMTP_URL`, ссылка уходит на email. Если нет — заявка появляется у администратора в настройках, он копирует ссылку и передаёт лично.

## Разработка

```bash
npm install
npm run dev      # API на :8080, фронт на :5173
npm test
```

Стек: Node 22+/Express 5/`node:sqlite`, Vite + React. Подробности в `CLAUDE.md`.

## Релиз

1. Поднять `version` в `package.json`, дописать `CHANGELOG.md`.
2. `git tag v0.2.0 && git push origin main --tags`.
3. GitHub Actions прогонит тесты, соберёт образ `ghcr.io/alexbelens/training:v0.2.0` и `latest`, создаст Release. Клиенты увидят баннер обновления.
